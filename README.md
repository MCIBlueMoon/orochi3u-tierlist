# 无双大蛇3 Ultimate · 全人物自定义排位

一个单文件的《无双大蛇3 Ultimate》全人物排位工具：**177 位角色**，单击角色即可查看该角色在 B 站专栏里的完整心得（类型、神器、武器、每一招的分析与连招思路），并支持自由拖拽重排、自定义档位、本地保存与导入导出。

## 功能

- **13 档排位**：SSS+ / SSS / SS+ / SS / S+ / S / A+ / A / B+ / B / C / D / E，内置原始排名
- **单击看心得**：左侧全身立绘 + 右侧可滚动心得正文，`‹ ›` 或 `←` `→` 连续翻阅相邻角色
- **自由编辑**：拖拽换档／档内排序；档位名称、说明、颜色均可改；可新增/删除/上移/下移档位
- **未分配池**：拖到底部「未分配」可暂时摘出某个角色
- **移动模式**：触屏友好——点角色选中、点档位放下，`Esc` 退出
- **自动保存**：改动写入 `localStorage`，另可导出/导入 JSON 备份
- **术语速查**：`8方`、`C技`、`神速攻击`、`S技`、`五角` 等缩写内置解释
- **纯静态**：单文件 `index.html` + 本地图片，无任何框架与外部依赖，断网可用

## 目录结构

```
index.html   # 全部页面、样式与数据（心得正文已内嵌）
img/         # 354 张 WebP：176+1 名角色的头像与全身立绘
```

## 本地使用

直接用浏览器打开 `index.html` 即可（`img/` 需与它同级）。
